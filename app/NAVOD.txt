WHS ASISTENT – PRENOSNY BALICEK
Rozbalte ZIP do zapisovatelne slozky a spustte WHS-Asistent.bat.
Windows 10/11 x64, Microsoft Edge a internet pri prvnim spusteni.
Python neni nutne instalovat do Windows. Spoustec stahne uv, Python 3.13 a zavislosti do .runtime. Nemeni systemovy PATH. Stahovani vyzaduje pristup na GitHub, PyPI a servery Microsoftu pro EdgeDriver.
Prvni spusteni nabidne nastaveni instance a prihlaseni. Konfigurace a vysledky jsou v data; heslo je ulozene jako text. Tuto slozku nesdilejte.
1 – Zpracovani WHS objednavek. 2 – Kontrola bez zmen.
Volba 2 pouze vypise aktualni stav objednavky. Neprovadi realizaci, HW ani uzavreni, ani pri zadani --r.
Login a heslo se zadavaji jednou pro prednastavene sys2, int a pre. Ze stare konfigurace se znovu pouziji shodne udaje; existujici instance se neprepisuji.
WHS_SO_08000006785 znamena cely postup.
WHS_SO_08000006786 --r znamena pouze realizaci zasuvky (--realizace funguje take).
Vkladejte WHS nejlepe po jednom na radek. Prazdny radek spusti davku. Potvrzeni y/n. WHS ma prefix WHS_SO_ a presne 11 cislic.
--help nebo --h zobrazi napovedu. Sipky nahoru/dolu vybíraji historii WHS tohoto behu.
Postup: Ceka na prirazeni -> realizace zasuvky -> Ceka se na odpoved WHS partnera -> Registrace CM provedena -> HW -> uzavreni.
Pred registraci CM se HW neprovadi. Pri CEKA_NA_CM zadejte stejne ID znovu po registraci. Pro HW musi byt MAC neprazdna; format se nekontroluje.
Realizace zrusena je konecny stav. Pri kontrole i zpracovani vrati REALIZACE_ZRUSENA a pokracuje dalsim WHS bez instalace a uzavreni. Nezahrnuje se mezi uspesne dokoncene objednavky.
HW a uzavreni zatim vyzaduji rucni overeni vysledku y/n. Cely postup potvrzuje i uzavreni pred terminem. Zpravy o dokonceni obsahuji pouze potvrzene vysledky; samotna realizace ma vlastni text.
Ctrl+C behem davky prerusi automat a ponecha Edge ke kontrole. Pri chybe lze preskocit objednavku a po overeni prehledu pokracovat.
Pri zadavani WHS napiste .. nebo stisknete Ctrl+C pro navrat do menu bez zavreni Edge. Volba 1 nebo 2 prepne rezim; rozepsana davka i historie zustanou zachovane. Volba 0 v tomto menu ukonci beh a zavre Edge.
Kazdy beh otevre novy Edge; ulozene relace se neobnovuji. Mezi davkami zustava stejny prohlizec. Nejiste odeslani se automaticky neopakuje. data/vysledky.jsonl nemazte.
Pri nulovem vysledku probiha az 5 opakovani po 60 sekundach. Chybna nebo nejednoznacna stranka neni nulovy vysledek.

STRUKTURA
WHS-Asistent.bat – jediny vstup pro uzivatele.
app – kod, napoveda a priprava lokalniho prostredi.
.runtime – automaticky stazene soubory, nevkladaji se do ZIPu ani Gitu.
data – soukroma konfigurace a vysledky, nevkladaji se do ZIPu ani Gitu.
tests a package.ps1 – pouze pro vyvoj; nejsou v uzivatelskem ZIPu.
package.ps1 vytvori cisty ZIP v dist bez konfigurace, historie, profilu Edge, Pythonu a cache.
Rucni baleni: .\package.ps1 -Version v0.2.3 vytvori dist/WHS-Asistent-v0.2.3.zip. Verze je povinna; casove razitko se nepouziva. Existujici ZIP stejne verze se neprepisuje.
GitHub Actions prevezme verzi automaticky z odeslaneho tagu (napr. v0.2.3) a prilozi prave tento ZIP k vydani.
Stare app/.venv a data/browser_sessions se nepouzivaji. Zustaly lokalne; nejsou soucasti distribuce.
Po presunu jiz pripravene slozky muze byt potreba obnovit .runtime, protoze Python prostredi muze obsahovat absolutni cesty. Nejsnazsi je rozbalit cisty ZIP v cilovem umisteni a prenest pouze vlastni data.
